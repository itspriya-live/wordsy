# Wordsy 📖 — Personal Vocabulary Training

A spaced-repetition system to actively learn ~743 English words for daily speaking.

## What's here
| File | Purpose |
|------|---------|
| `WORDSY-LLM-GUIDE.md` | Paste into any LLM to make it coach you exactly as before |
| `vocabulary-master-list.md` | All 743 words, A–Z |
| `word-index.md` | Words grouped into 24 themes, utility-first teaching order |
| `learning-progress.md` | Live tracker: progress, current position, review queue |

## Resume on a new machine / new LLM
1. Clone this repo.
2. Tell your LLM: *"Read `WORDSY-LLM-GUIDE.md` and the three data files, confirm my
   position from `learning-progress.md`, run any reviews due today, then teach the next 3 words."*
3. After each session, have it update `learning-progress.md` and commit.
